## 🔴 1.【最重要】Gemini を有償（paid tier）に移行

現在のキーは **free tier（20 リクエスト/日）** のため、日常のディクテーション利用（ドッグフーディング）も、S3-T2 のモデル比較（Flash-Lite vs Haiku）も、すぐ quota 切れで止まります。**Phase 1 の品質判定はドッグフーディングが前提なので、これがクリティカルパスです。**

1. ブラウザで **https://aistudio.google.com** → 「Get API key」。
2. キーに紐づく **Google Cloud プロジェクトで課金（Billing）を有効化**（クレジットカード登録）。
   - 課金有効プロジェクトのキー ＝ paid tier ＝ **入力内容が学習に使われない**（プライバシー方針の必須条件）。
3. paid tier になったキー文字列をコピー（既存キーのプロジェクトに課金を付けた場合は再発行不要のこともあります。不明なら新規発行が確実）。
4. **自分のターミナル.app** で実行（`-U` は上書き更新）:

   ```
   security add-generic-password -s dev.newt.Koe -a geminiAPIKey -w 'ここにキー' -U
   ```

5. チャットで「**Gemini を paid tier にした**」と伝える → Claude が疎通確認と golden-set 回帰（S3-T2 のフル A/B）を実行します。

> 費用目安: 従量課金。個人利用なら月数百円程度の想定です。

## 🔴 2. 実機 QA その1 — 初回起動と権限付与（E2E ディクテーション）

実装は済んでいますが、**macOS の権限ダイアログはあなたにしか押せません**。初回起動でオンボーディング（6 ステップ）が自動表示され、順に案内します。

**起動方法**:

```
brew install xcodegen        # 未導入なら一度だけ
xcodegen generate            # project.yml 変更後に再生成
open Koe.xcodeproj           # Xcode で ▶ Run
```

**出てくるダイアログと対応**:

| ダイアログ | 対応 |
| --- | --- |
| APPI（個人情報）同意画面 | 内容を読んで同意 |
| マイクの使用許可 | 許可 |
| アクセシビリティ許可 | システム設定で Koe を ON（付与直後に「再起動して続行」と出たら従う） |
| Keychain アクセス許可（初回のキー読み取り時） | **「常に許可」** |
| 「System Events を制御」（Automation、貼り付け経路2の初回） | 許可 |

**ホットキー設定**（オンボーディング内で案内あり）:

- Fn（🌐）キーを使う場合: システム設定 > キーボード > 「🌐キーを押して」→ **「何もしない」**
- 代替は **⌥Space**（TCC 不要、最初はこちらが確実）

**基本動作の確認**: ⌥Space（または Fn）を**押しながら話し、離す** → フォーカス位置に整形済みテキストが挿入されれば成功。結果（OK / ダメだった点）をチャットで返してください。

## 🟠 3. 実機 QA その2 — マイルストーン別チェック

基本動作が通ったら、以下を順に。各項目の詳細チェックリストは該当 PR の本文にもあります（必要なら「◯◯ の QA チェックリストを出して」でチャットに出します）。

- **挿入（M5）**: TextEdit / Slack / Terminal / Claude Code に挿入できる。⌘Z で挿入テキストだけが丸ごと消える。挿入後にクリップボードの元の内容が復元される。パスワード欄では挿入がブロックされる。DEBUG メニューの項目で経路 1/2/3 を強制して各経路の着地を確認。
- **ネットワーク断（M4-T3）**: 発話中に Wi-Fi を切る → batch 再送で復旧するか、HUD のリトライボタンで再試行できる。テキストが消失しないこと。
- **HUD（M9）**: 表示中にフォーカスを奪わない。日本語 IME の変換を邪魔しない。フルスクリーンアプリの上にも表示される。
- **音声デバイス（M3-T2）**: AirPods で話している最中に外す → 内蔵マイクに切り替わり、1 発話として最後まで転写される。
- **履歴 UI（M7-T2）**: ⌘Y で履歴。検索・コピー・👎・削除・全削除が動く。
- **設定（M10-T1）**: 4 タブ（一般/辞書/アプリ別/API キー）の変更が再起動なしで反映される。
- **統計（M10-T2）**: 何回か使った後、設定「統計」タブに遅延 P50/P95・👎率が出る。
- **オンボーディング再走（M11-T1）**: 権限をリセットしてフルフローが 3 分以内で完走する:

  ```
  tccutil reset Accessibility dev.newt.Koe
  tccutil reset Microphone dev.newt.Koe
  ```

- **権限剥奪（M11-T2）**: 動作中にシステム設定でアクセシビリティを OFF → 60 秒以内にメニューバーが ⚠︎ → 再度 ON → 5 秒以内に復帰（再起動不要）。
